SOLAR WITH PHILIP - PROPOSAL PACKAGE

THIS VERSION MATCHES THE EXISTING REPOSITORY STRUCTURE.

Existing root items stay where they already are:
- admin/
- assets/
- energy-strategies/
- landing/
- existing site HTML files
- existing README-FIRST.txt, README.md, VALIDATION.json and CNAME

THIS PACKAGE ONLY DOES THE FOLLOWING AT REPOSITORY ROOT:
1. Replaces proposal.html
2. Replaces assets/css/proposal.css
3. Replaces assets/js/proposal.js
4. Adds one proposal/ folder
5. Adds netlify.toml so Netlify knows that proposal/functions contains the server functions

Everything specific to the Proposal system is inside proposal/:
proposal/
  manifest.json
  shared/
  sections/
  components/
  functions/
  setup/

ENVIRONMENT VARIABLES TO ADD IN NETLIFY
GOOGLE_SOLAR_API_KEY
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY

DO NOT PUT SECRET VALUES IN GITHUB.

SUPABASE
Run proposal/setup/proposal-schema.sql once in the Supabase SQL Editor.

MODULARITY
- Redesign a section: replace only that section's files.
- Redesign a graph/card/diagram: replace only that component's files.
- Add/remove/reorder components: edit proposal/manifest.json.
- Server integrations remain independent under proposal/functions/.
