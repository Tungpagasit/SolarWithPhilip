Seasonal import model

Higher annual production can reduce the expensive winter gap.

Each card estimates remaining utility imports, surplus exports, and annual utility energy cost using the same utility rate from Section 2 and a $0.07/kWh export-credit assumption.

Approximation: battery operation is treated as improving daily self-use, but a battery cannot carry summer energy into winter. Fixed charges, non-bypassable charges, interval dispatch, and tariff-specific values are not included.
