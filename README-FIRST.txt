SOLAR WITH PHILIP - GITHUB-READY WEBSITE

This package preserves the complete uploaded website: all ten HTML pages, visible wording, links, forms, colors, fonts, spacing, responsive rules, and page behavior.

The only structural revision is that large embedded code and images were separated into easy-to-edit folders:

- HTML pages remain in the repository root.
- Page styling is in assets/css/.
- Page JavaScript is in assets/js/.
- Embedded images are in assets/images/.

UPLOAD TO GITHUB
1. Back up the current repository.
2. Upload every HTML file from this package to the repository root.
3. Upload the entire assets folder, preserving its subfolders.
4. Keep the filenames and folder paths exactly as provided.

Do not upload the ZIP itself as the website. Extract it first, then upload its contents.
